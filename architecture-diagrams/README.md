# Architecture Diagrams

This directory stores architecture descriptions used in portfolio walkthroughs, design reviews, and README visualizations.

## Included Views

- Logical architecture: described in the root `README.md` Mermaid diagram
- Delivery flow: GitHub Actions to Azure and AKS
- Observability flow: Prometheus scrape, Grafana visualization, and alert evaluation

## Presentation Tip

For GitHub and LinkedIn showcases, pair the Mermaid diagram with a short narrative around:

- platform provisioning
- workload deployment
- observability
- security controls
